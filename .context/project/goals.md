# Project goals

1. Provide a Windows application that replaces the current Postman workflow.
2. Support multiple independent prize-wheel modules rather than hard-coding one AlfaBank flow.
3. Keep authentication/session state reusable for as long as the remote server accepts it.
4. Support both browser login and manual cookies/headers import.
5. Make all material HTTP request parameters visible and editable.
6. Keep confirmation/mutating steps explicit rather than automatically executing them.
